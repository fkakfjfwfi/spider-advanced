## 学习现状评估

| 你已具备 | 你的瓶颈 |
|---|---|
| Python 基础、requests 抓静态页 | 网站一有反爬（Cookie 校验、接口加密、频率限制）就卡住 |
| 跟着教程做过小案例 | F12 抓包不熟练，找不到数据真正的来源 |
| 有考研 408 的计算机基础（网络知识可迁移） | JS 逆向只看过书，没上手实战，越学越虚 |

**核心结论**：卡住的不是代码能力，而是「抓包分析」和「JS 调试」这两个动手技能。本计划以**练习平台闯关**为主线，书和视频只当字典查。

## 六阶段路线图

### 阶段 ① HTTP 基础 —— 看得懂请求（3~5 天）

- **目标**：面对任何网站，先说清数据从哪个请求来。
- **知识清单**：
  - [ ] HTTP 请求/响应结构：请求行、请求头、请求体
  - [ ] 关键请求头：User-Agent、Referer、Cookie 各管什么
  - [ ] Cookie 与 Session：登录态怎么保持
  - [ ] F12 Network 面板：筛选 XHR、查看负载、复制 cURL
  - [ ] 状态码族谱：200 / 301 / 403 / 429
- **资源**：[麦叔《1小时全面入门HTTP协议》](https://www.bilibili.com/video/BV165411A7ef) · [MDN HTTP 文档](https://developer.mozilla.org/zh-CN/docs/Web/HTTP)
- **练手**：任意网页 F12 找出"列表数据来自哪个请求"；把请求复制成 cURL 逐行看懂。
- **通关标准**：随便给一个网站，能说清数据写在 HTML 里还是藏在接口里。

### 阶段 ② 解析提取 —— 抓得下数据（1~2 周）

- **目标**：不用框架，独立爬完一个静态整站。
- **知识清单**：
  - [ ] requests：headers、timeout、失败重试
  - [ ] HTML/DOM 与 CSS 选择器
  - [ ] XPath 语法：层级、属性、文本
  - [ ] BeautifulSoup / lxml / parsel
  - [ ] JSON 与正则提取；存 csv / json / sqlite
- **资源**：[尚硅谷爬虫零基础速通](https://www.bilibili.com/video/BV1Db4y1m7Ho)（212万播放）· [wistbean/learn_python3_spider](https://github.com/wistbean/learn_python3_spider)（22k star）
- **练手**：quotes.toscrape.com 整站；books.toscrape.com 按分类爬图书。
- **通关标准**：零框架爬完一个静态整站，数据干净落库。

### 阶段 ③ 动态页面 —— 对付"滚出来"的数据（1~2 周）

- **目标**：右键源代码里没有的数据，你有两条路都能拿到。
- **知识清单**：
  - [ ] AJAX 原理：页面没刷新，数据在悄悄加载
  - [ ] XHR/Fetch 抓包：找到 JSON 接口直连
  - [ ] 接口参数分析：翻页、搜索、时间戳
  - [ ] Selenium / Playwright 自动化与等待策略
  - [ ] Cookie 复用登录；ddddocr 简单验证码
- **资源**：尚硅谷 Ajax 章节 · [Scrape Center](https://scrape.center)（崔庆才《Python3网络爬虫开发实战》配套练习平台，53 关）
- **练手**：scrape.center spa1→spa5；找一个无限滚动页面爬到底。
- **通关标准**：spa 关卡全清。

### 阶段 ④ 反爬攻防 —— 摸清黑名单套路（2~3 周）

- **目标**：单站稳定采集上千页不被封。
- **知识清单**：
  - [ ] 反爬全景：UA 检测、频率限制、IP 封禁、Cookie 校验
  - [ ] 请求头伪装 + 随机延时
  - [ ] 代理池：IP 来源、调度、验活
  - [ ] 验证码：图形 OCR、点选/滑块思路
  - [ ] 字体反爬与 CSS 偏移
- **资源**：[Spiderbuf 闯关平台](https://github.com/hhuayuan/spiderbuf) · scrape.center antispider1→9
- **通关标准**：antispider 系列全清。

### 阶段 ⑤ JS 逆向 —— 分水岭（1~2 个月，最值得投入）

- **目标**：独立还原加密参数，稳定出数。
- **知识清单**：
  - [ ] Sources 断点调试：XHR 断点 + 调用栈回溯
  - [ ] 全局搜索关键字；Console Hook 拦截
  - [ ] 算法识别：MD5 / Base64 / AES / DES / RSA、CryptoJS 特征
  - [ ] 扣代码 + 补环境：把 JS 抠到 Node 里跑通
  - [ ] Webpack 打包结构、ob 混淆还原、AST 初识
- **资源**：[JS逆向实战教程（B站，21小时）](https://www.bilibili.com/video/BV1TC1jYmEve) · [猿人学 match 平台](https://match.yuanrenxue.cn)（圈内公认刷题圣地，走出过 20+ 逆向大佬）· [python-spider.com 挑战题](https://www.python-spider.com/challenge/)
- **方法论**（逆向三板斧，每题都走一遍）：
  1. **定位**：Network 找到带加密参数的请求 → XHR 断点/搜索参数名定位生成处
  2. **分析**：断点单步跟栈，识别加密算法与关键变量
  3. **还原**：扣 JS 代码到 Node 补环境跑通 → 移植 Python → 写成逆向笔记
- **通关标准**：猿人学 match 1~10 题独立解出，每题有笔记。

### 阶段 ⑥ 工程化 —— 从脚本到系统（2~4 周）

- **目标**：交付可定时运行、失败报警、增量更新的采集系统。
- **知识清单**：
  - [ ] Scrapy：Spider / Item / Pipeline / Middleware
  - [ ] asyncio + httpx / aiohttp 异步爬取
  - [ ] 增量去重、断点续爬、任务调度
  - [ ] 分布式 Scrapy-Redis、监控告警
  - [ ] App 方向：mitmproxy 抓包、Frida Hook 入门
  - [ ] 合规红线：robots 协议、《数据安全法》边界、频率礼仪
- **资源**：[黑马 Scrapy 框架](https://www.bilibili.com/video/BV1jx411b7E3) · [Scrapy 官方文档](https://scrapy.org)
- **通关标准**：把阶段 2-5 的脚本重构成一个带调度与告警的采集项目（可以直接服务于你的考研择校、408 数据任务）。

## 教学约定（接下来我们这样上课）

1. **每课一个可视化课件** + 一个动手任务，我讲原理，你动手跑。
2. **卡住就把报错/抓包截图发我**，我带你分析而不是直接给答案。
3. **进度打卡**：路线图课件里的勾选会自动保存，下次上课先对进度。
4. **以战代练**：学完阶段③就用"考研择校 / 408 大观园"的真实数据需求当项目练。

## 合规提醒（每阶段都要记得）

- 只采公开数据，遵守 robots.txt 与网站服务条款；
- 控制频率（建议 ≥1~3 秒/请求），深夜跑大批量任务；
- 不绕过登录权限拿非公开数据，不碰个人信息倒卖类需求；
- 逆向练习仅限猿人学/scrape.center 这类**授权练习平台**与学习用途。
