多源图书馆

本站知识体系以崔庆才《Python3网络爬虫开发实战（第二版）》为主线，但一个好的爬虫工程师不该只读一本书。这里汇总了全网经得起检验的书籍、网课、博客、开源仓库与工具，按知识域组织，每条都给出"为什么值得 + 怎么读"。每章末尾的"多源精读"框会把你带到本页对应条目。

三条混合阅读路径（选一条主线，其余当字典）

📗 路径一 · 书本主线（最扎实）

崔庆才二版逐章推进 + 本站每章打卡 → 反爬专题切韦世东《反爬虫原理与绕过实战》 → 框架深入读《精通Scrapy网络爬虫》 → 视野扩展翻Ryan Mitchell《Python网络爬虫权威指南》（英文版已出第3版）。

📺 路径二 · 视频主线（最省心）

尚硅谷爬虫速通打基础 → 黑马 Scrapy 过框架 → JS逆向 21h 攻逆向 → 本站当讲义与练习场。

🔬 路径三 · 实战研究线（最接近高手）

书当字典，主力啃案例：K哥《JS逆向百例》+ 夜幕团队系列 精读 → 猿人学逐题实战 → 卡点回本站对应章节补理论。

⚙️ 用法提醒

多源的价值是互补视角：崔书体系全、韦书攻防深、Mitchell 书伦理与清洗、K哥/夜幕案例新。同一知识点读两个来源仍糊涂，说明缺的是动手——回练习场。

🧱 网络基础与抓包（ch01）

📚 《HTTP权威指南》（David Gourley 等）—— 把 HTTP 读厚的字典；爬虫人重点读前 5 章 + Cookie/连接管理章节。 ch01

📚 《Python网络爬虫权威指南（第2版）》（Ryan Mitchell，O'Reilly；英文版已出第3版）—— 第 1~3 章"你的第一个爬虫/高级HTML解析"，国际视角 + 抓取礼仪。 ch01~03

📄 MDN HTTP 文档—— 报文/方法/CORS/Cookie 的权威手册，遇到不确定的头就查它。 ch01

📨 请求 / 解析 / 存储（ch02~04）

📄 requests 中文官方文档—— 快速上手+高级用法两篇读完，requests 就算毕业。 ch02

🛠 regex101.com—— 正则在线调试器，实时解释每个符号；练正则别在爬虫里试错，在这里练熟再上。 ch02

📄 lxml 官方文档 / BeautifulSoup 中文文档—— 两大解析库权威手册。 ch03

🛠 KGtools 在线工具箱（K哥出品）—— cURL 转代码、JSON 格式化、正则/XPath 在线测试，25 个爬虫常用工具合一。 ch02~03·08

📚 《Python网络爬虫权威指南》第 5 章"数据库"—— 存储选型的另一个视角。 ch04

⚔️ 动态渲染 / 验证码 / 反反爬（ch05~07）

📄 Playwright 官方文档—— 自动等待与网络拦截是现代自动化的事实标准，教程+API 通读。 ch05

📚 《Python3反爬虫原理与绕过实战》（韦世东 等，崔庆才作序推荐）—— 反爬知识体系最系统的中文书：字体反爬/CSS偏移/指纹/JS混淆全覆盖，第 07 章的天然续篇。 ch06~07

📦 Kr1s77/awesome-python-login-model—— 数十个网站模拟登录源码合集，登录方法论的最佳实操场。 ch06

📦 sml2h3/ddddocr—— 验证码 OCR 库官方仓库，README 就是完整教程。 ch06

📦 jhao104/proxy_pool—— 高星开源代理池，架构与第 07 章"四模块"完全对应，读源码学工程。 ch07

🔍 JS 逆向 / App（ch08~09）

📝 K哥《JS逆向百例》专栏（掘金）—— 一百个真实案例按套路分类，逆向人的案例字典；配套博客园 K哥爬虫 与工具箱 KGtools。 ch08

📝 夜幕团队 NightTeam（博客园 · GitHub）—— 崔庆才也是成员；爬虫/反爬/JS 逆向深度系列，B站有《JS逆向高阶课》。 ch08

📦 GitHub · JSREI 组织—— JS 逆向研究与工具仓库集合（脚本、案例、课程资料）。 ch08

📺 编程奇遇 · JS逆向进阶全套 / B站搜"宇哥 JS逆向"—— 案例跟练向网课，与本站 ch08 讲义互补。 ch08

📄 mitmproxy 官方文档 / Frida 官方文档—— App 抓包与 Hook 的权威手册（Frida 文档建议直接啃英文，短）。 ch09

🏭 框架与工程化（ch10）

📚 《精通Scrapy网络爬虫》—— 把 Scrapy 从"会用"讲到"懂原理"（调度器/去重/中间件源码级）。 ch10

📄 Scrapy 官方文档—— Deployment / Jobs / AutosThrottle 三节是工程化精髓。 ch10

📦 crawlab-team/crawlab（夜幕系开源）—— 分布式爬虫管理平台，比教材里的 Gerapy 更活跃，部署章节的现代替代。 ch10

📦 wistbean/learn_python3_spider（22k★）/ facert/awesome-spider—— 教程仓库与实战案例索引，找"某类网站怎么爬"先翻这里。 全站
